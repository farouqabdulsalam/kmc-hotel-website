# kMC Hotel Website

Responsive website for kMC Hotel, Karu, Abuja, using the Modern Sandstone visual direction and photographs supplied for this project.

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually `http://localhost:5173`).

## Details found in the public business listing
- Address: Plot MF57 Cadastral Zone, Karu, Abuja, FCT.

## Before publishing
- Confirm the hotel has approved the supplied photographs for website use.
- No room photos were supplied; the current gallery uses the exterior, gym and property signage photos supplied by the client.
- Confirm exact accommodation categories, rates, facilities, hours, policies and booking procedures with hotel management.
- The booking form opens a WhatsApp enquiry. It does not check live availability or create a confirmed reservation.
